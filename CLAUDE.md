# Portafolio — José Roberto Mendoza

Portafolio profesional y CV en línea. Enfocado en el cruce de educación, IA y rendimiento deportivo. Es la carta de presentación pública de José — se comparte en procesos laborales reales (USICAMM, universidades).

## Stack
Vite. Tipografía con fuentes de sistema de Apple.

## Comandos
```bash
npm run dev
npm run build
npm run deploy    # gh-pages -d dist
```
